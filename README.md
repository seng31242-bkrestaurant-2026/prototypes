# Prototypes Repository

## Purpose
This repository contains the **UI/UX Design** artifacts for the SENG 31242 System Design Project. It serves as the central hub for wireframes and interactive prototypes.

## Directory Structure
- `wireframes/`: Low-fidelity sketches and structural layouts.
- `figma-exports/`: Exported static images (PNG/SVG) and documentation from Figma.
- `low-fi-prototypes/`: Functional low-fidelity prototypes (e.g., PDF click-throughs or Framer exports).

## Tooling
- Figma / Adobe XD / Balsamiq.
- Image viewers for SVG/PNG exports.

## Standards
All design updates must be documented using the commit and branching conventions in `CONTRIBUTING.md`.
